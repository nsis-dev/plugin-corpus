FreeArc for NSIS.
This plugin provides basic FreeArc file archive extraction ability for NSIS scripts.

If you want to use this plugin you must compress your archive with FreeArc. 
http://freearc.org/



To Test and Install FreeArc for NSIS plugin 

- Copy Plugin\FreeArc.dll to NSIS\Plugin Directory.
- Compile the Example\Example.nsi and test it.


For Programmers (Only):
To Compile the plugin source code you must download FreeArc Source code from http://freearc.org/ 
Follow the FreeArc Compiling instructions.
Then copy and replace my sourcecode files to "C:\!\FreeArchiver\Unarc".
